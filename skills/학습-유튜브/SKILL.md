# 학습-유튜브 스킬

## 사용법
```
/학습-유튜브 <YouTube URL>
```
주제는 영상 내용을 보고 자동 판단한다. 사용자에게 묻지 않는다.

---

## 동작: 범용 서브에이전트에 파이프라인 위임

메인 세션은 URL 파싱 후 general-purpose 서브에이전트를 `run_in_background: true`로 스폰하고, 아래 파이프라인 전체를 프롬프트로 전달한다. 완료 알림 수신 후 결과(저장 경로·대주제·MOC 여부)를 보고한다.

## 파이프라인 (서브에이전트 수행)

시작 전 `{claude_home}\config.md` Read — `resources`, `study`, `scripts` 변수 확인.

### 1. 트랜스크립트 추출
```
python "{scripts}\youtube_transcript.py" <URL>
```
결과: `{title, transcript, url, video_id}`. 오류 시 내용 보고 후 중단.

### 2. 주제 자동 분류
대주제 선택 (없으면 2~4글자 한글 키워드로 신설): 클로드코드 / AI공부 / 건축PM / 스타트업 / 생산성

### 3. 노트 작성
파일명: `YYMMDD_유튜브_제목키워드.md` (한글 2~4단어 요약, 영어 원제 그대로 금지).

구성 (도요 노트 스타일):
- frontmatter: title/date/tags/type(개념정리·기능심화·실전가이드·사례분석)/status/source/url/subject/related
- `[!abstract]` 한 줄 정의 + `[!note]` 도요님 적용 포인트 (건설 PM·AI 전환·자동화 연결점)
- 섹션 2~6개, 제목 옆 **타임스탬프 `[mm:ss]`** 필수
- `[!summary]` 핵심 체크리스트 (5~10개)
- **플래시카드**: `[!question]` + 접이식 `[!success]-` 정답, 3~7개 (active recall)
- 맨 끝 "전체 스크립트 (참고용)" — 원문은 여기에만, 본문 덤프 금지
- 재사용 가치 있는 큰 개념은 atomic 노트 분리 + `[[개념명]]` 연결 (같은 폴더, type: 개념)

### 4. 저장
- **중복 확인 필수**: 대주제 폴더 Glob — 동일 url/제목 노트 있으면 갱신·건너뜀.
- 저장 경로: `{study}\<대주제>\` (config.md `study` 변수).
- 노트 수 ≥ 10개면 소주제 2~4개로 분리 + 소주제별 MOC + 대주제 개요 MOC 유지.

### 5. MOC
폴더 노트 3개 이상이면 `_<대주제>_MOC.md` 생성/갱신 (테이블 + dataview 쿼리).

### 6. 자기검증·보고
저장 후 파일 존재 + 타임스탬프·플래시카드 포함 확인 → 저장 절대경로·대주제·MOC 여부 보고. 같은 단계 2번 막히면 중단·원인 보고.
