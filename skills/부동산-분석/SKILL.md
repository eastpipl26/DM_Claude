# 부동산-분석 스킬

## 사용법
```
/부동산-분석 <단지명 또는 지역>
/부동산-분석 송도 SK뷰 8공구
/부동산-분석 송도 마스터뷰 21단지, 22단지, 글로벌파크베르디움 비교
```

---

## 동작: 파싱 후 즉시 위임

메인 세션은 아래 2단계만 수행한다. 실제 작업은 **terra**가 전담한다.

### 1단계: 입력 파싱
- 단지명 1개 → 단일 분석 / 단지명 2개 이상 → 비교 분석

### 2단계: terra에게 위임 (`run_in_background: true`)

terra에게 전달:
- 대상 단지명·지역, 비교 여부
- 데이터 수집(국토부 실거래가 API·네이버부동산·KB·호갱노노 크롤링)과 분석·제안까지 terra가 자체 수행 (수집 방법은 terra md에 내장)

terra 완료 보고 수신 후 도요님께 결과 전달: 저장 경로(절대경로), 결론(관망/매수), TOP 추천.
