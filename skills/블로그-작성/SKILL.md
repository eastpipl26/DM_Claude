# 블로그-작성 스킬

## 사용법
```
/블로그-작성 <폴더경로 또는 파일경로들> [주제]   ← 모드 1 (사진 기반)
/블로그-작성 <주제 텍스트>                        ← 모드 2 (주제 자동)
```

---

## 동작: 파싱 후 즉시 위임

메인 세션은 아래 2단계만 수행한다. 실제 작업은 **piper**가 전담한다.

### 1단계: 입력 파싱 + 모드 판별
- 이미지 경로(폴더/.jpg/.png 등) 있으면 → **모드 1 (사진 기반)**
- 텍스트만 있으면 → **모드 2 (주제 자동)**

### 2단계: piper에게 위임 (`run_in_background: true`)

piper에게 전달:
- 모드 1: 이미지 경로 목록/폴더 + 주제(있으면)
- 모드 2: 주제 텍스트

모드 2에서는 piper가 리서치·SEO·검수 서브에이전트를 직접 스폰해 오케스트레이션한다 (piper md 참조). 체인 내부 스폰은 foreground로 — 결과를 기다렸다가 다음 단계 진행.

piper 완료 보고 수신 후 도요님께 전달:
- 저장된 파일 경로(절대경로)
- (모드 1) 이미지 복사 경로 / (모드 2) 글 유형·출처 수·검수 통과 여부
