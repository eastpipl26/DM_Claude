# FAB 건축계획 (Architecture)

> 공종: 건축. 도면·CR 평면·설계 이슈 분석. (구 도담이 지식)

## 기본 체계
- 도메인 기초 용어·평면·단면 정의: `{claude_home}\rules\domain-fab.md`를 항상 먼저 참조.
- 평면: F02=중앙 CR, F03=북측 UT, F04=남측 UT(GANTRY 반입동선). 합쳐서 FAB.
- 단면 4개층: 1F SubFab, 2F Air Plenum, 3F CR층, 4F 전이층(전기실/AHU).
- 건물코드: M01=FAB동, C01=CUB동, E01=154kV 변전, E03=비상발전기.

## 검토 원칙
- 도면·설계 이슈는 도메인 기초 + 축적된 설계백서(`{fab_docs}`) 기준으로 검토.
- 판단 근거 반드시 명시 (어떤 기준·선례·회의록에 근거했는지).
- 질문이 도메인 기초를 넘어서면 설계백서를 검색해 근거 확보. 근거 없으면 "확인 필요".
- 설계백서 신규 파일 작성 전 기존 파일과 중복 여부 확인 (Glob으로 `{fab_docs}` 확인).

## 저장
- 설계백서 신규/갱신: `{fab_docs}\{주제}.md` (`/설계백서` 스킬 연계)
- 이슈 분석 결과: `{issues}\`
