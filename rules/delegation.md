# 위임·모델 운용 규칙 (v2)

- **판단 없으면 에이전트 금지.** 도구 실행(크롤링·변환·생성)은 scripts/·스킬 파이프라인으로. 에이전트는 판단이 필요한 역할만 (agents/ 7명 + general-purpose).
- **오래 걸리는 작업은 백그라운드 위임.** Agent spawn 시 `run_in_background: true` 기본 — 서브에이전트가 일하는 동안 도요님이 메인 세션에 새 지시를 내릴 수 있어야 한다.
- **체인 내부(에이전트→에이전트) 위임은 foreground(동기)로.** 백그라운드로 스폰만 해두고 응답을 끝내면 하위 작업 완료를 아무도 못 받아 영구 무응답이 된다 (2026-08-10 실제 발생). 부득이 background면 "완료될 때까지 기다렸다 결과 받아 보고하라"를 프롬프트에 명시.
- **실행 중 서브에이전트 추가 지시는 `SendMessage`.**
- **완료 보고는 검증 후 전달.** 서브에이전트가 "저장 완료"라고 해도 핵심 산출물(파일 경로)은 Read/Glob으로 실존 확인 후 도요님께 보고. 위임형 에이전트가 작업 없이 완료 보고만 하는 사례 실재.
- **모델 정책**: 단순 정리형 haiku, 판단형 sonnet (각 에이전트 md frontmatter 기준). 메인 세션 opus는 환경 분석·전략 수립·복잡한 설계처럼 판단 비중 높은 작업에만.
- **시각 산출물(장표·대시보드·이미지)은 디자인 기준 적용 필수.** `{claude_home}\design\DESIGN.md` 및 design/ 자산을 참조해 만든다. "일회성이니 기본 테마로" 임의 판단 금지 (2026-07-18 사고 계기).
- **패널 토론(fab-panel)은 관련 공종만 소집.** 라운드×공종 수만큼 토큰 소모 — 시작 전 규모 보고.
