# v2 재구축 가이드 (경로 체계 + 마이그레이션)

> 작성: 2026-09-01. 이 문서는 .claude 및 Obsidian vault 재구축의 청사진이다.
> 실행 세션은 이 파일을 먼저 읽고, 완료한 단계에 체크 표시를 남긴 뒤 커밋한다.

---

## 0. 설계 원칙

1. **판단 없으면 에이전트 금지.** 도구 실행(크롤링·변환·생성)은 `scripts/` 또는 스킬. 에이전트는 판단이 필요한 역할만.
2. **지식과 실행 분리.** 도메인 지식은 `knowledge/` 파일. 에이전트 md는 역할·판단기준만 담아 얇게 유지.
3. **경로는 config.md 단일 소스.** 에이전트·스킬·스크립트에 경로 하드코딩 금지. 반드시 `{변수}` 참조.
4. **이름은 기능 연상형 외국계.** 대조표 없이 역할이 짐작되는 이름.
5. **삭제 대신 아카이브.** 구 자산은 `99_Archive`(vault) / `archive/`(.claude)로 이동. 되돌릴 수 있게.

### FAB 패널 토론 (`/fab-panel` 스킬)

1. Archie가 이슈를 받아 관련 공종 선별 (전 공종 소집 금지 — 관련만).
2. 1라운드: 선별된 공종 수만큼 범용 서브에이전트 병렬 스폰. 각자 담당 knowledge/fab/*.md만 로드, 독립 검토 (서로 의견 안 봄 — 앵커링 방지).
3. 2라운드: 각 패널에게 타 공종 의견 전달, 반박·보완 수집.
4. Archie가 합의안 + 남은 쟁점 정리해 보고.
5. 단일 공종 질문은 토론 생략 — Archie 혼자 해당 지식파일 로드 (저비용 경로).
