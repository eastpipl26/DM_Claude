용인 클러스터 프로젝트에서 Phase를 표기할 때는 하이픈 없이 쓴다: `Ph1`, `Ph2`, `Ph4` (❌ `Ph-1`, `Ph-2`).

예외: 프로젝트명 `Y-1`은 하이픈을 유지한다 (`Y-1 Ph1`처럼 조합).

**Why:** 도요님이 실제 사내 표기 기준으로 지정한 규칙 — Phase 뒤에 붙는 숫자는 하이픈 없이, 프로젝트 코드명(Y-1)만 하이픈 포함.

**How to apply:** 회의록·업무 아이템 제목·본문에서 Phase를 언급할 때마다 이 표기를 따른다. [[feedback-meeting-note-format]]의 `[Y-1 Ph1]` 태그 표기와 함께 적용.
