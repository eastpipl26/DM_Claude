리포트나 조사 결과에서 나온 명백한 후속 작업(파일 갱신, 결과 저장 등)은 매번 "이거 할까요?"라고 되묻지 말고 바로 실행한 뒤 결과를 보고한다.

**Why:** 은수(CFO)가 재무현황 리포트를 만들면서 "부동산 계약 반영해서 자산현황.md 갱신할까요? 리포트 저장할까요?"라고 되물었을 때, 도요님이 "당연히 갱신해야하는거고. 저장해야지. 은수가 자동적으로 해야할 일은 알아서 좀 했으면 좋겠어"라고 명확히 불만을 표함. 이런 확인은 마찰만 늘리고 판단이 필요한 일도 아니었음.

**How to apply:** 위임 지시를 내릴 때 "명백한 후속 조치는 재확인 없이 바로 실행하라"를 기본으로 명시한다. 정말 판단이 갈리는 선택(예: 삭제, 외부 전송, 금전적 결정)만 되묻고, 조사 결과를 근거로 자기 담당 파일을 갱신·저장하는 수준은 직원 재량으로 처리하게 한다. [[terll-maintenance]]류 반복 관리 작업도 같은 원칙 적용 가능.
