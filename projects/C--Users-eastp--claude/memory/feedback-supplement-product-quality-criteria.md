영양제/보충제 제품 추천 시 쇼핑몰(아이허브 등) "추천순"·광고 상위 결과를 그대로 가져오면 안 된다.

**Why:** 도요님이 유튜브 약사 콘텐츠와 비교 요청을 했을 때, 검색순위 기반 추천이 전문가(약사) 추천보다 명백히 부실하다는 게 드러남. 약사는 원료사(KD파마, 알비온 등)·순도(%)·제3자 인증(NSF)·자체 검사·보장균수(유산균 CFU, 유통기한까지 보장) 같은 실질 기준으로 골랐는데, 나는 브랜드 인지도+검색노출만 보고 골라 유산균 등에서 근거가 부실한 제품을 제안했다 (2026-08-19).

**How to apply:**
- 영양제/보충제 추천 시 다음을 우선 확인: ①원료 공급사, ②순도/함량(%), ③제3자 인증(NSF 등) 또는 자체 품질검사 여부, ④유산균이면 보장균수와 유통기한 보장 여부·균주 특허 여부, ⑤가격을 월 환산해서 mg/원 단위로 비교.
- 확신이 없으면 신뢰할 만한 전문가 콘텐츠(약사·영양사 유튜브/블로그)를 먼저 찾아 교차검증한 뒤 제품을 고른다.
- 아이허브 등에서 검색만 하고 상위 결과를 바로 제시하지 않는다.
