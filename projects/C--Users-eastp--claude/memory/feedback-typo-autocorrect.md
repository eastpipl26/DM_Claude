회의/메일 내용을 노트에 옮길 때, 명백한 도메인 용어 오타(예: AFC를 ARC로 잘못 말함)는 매번 확인받지 말고 문맥상 맞는 용어로 알아서 고쳐서 기록한다.

**Why:** 도요님이 "용어 나중에 오타나도 알아서 고쳐줘"라고 명시적으로 요청함 (2026-07-23, AFC를 ARC로 잘못 말한 것을 정정하며).

**How to apply:** 회의록/메모 로그 작성 시 익숙한 FAB/설계 도메인 약어(AFC, TER, LL, CR, UT 등— [[domain-fab]] 참조)가 문맥상 오타로 보이면 정정해서 기록. 애매하거나 새로운 용어면 그대로 두고 확인 요청.
