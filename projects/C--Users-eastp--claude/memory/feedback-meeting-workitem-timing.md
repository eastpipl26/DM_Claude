회의록 작성이 진행 중일 때는 각 안건마다 업무 아이템(items/*.md)을 즉시 생성·수정하지 않는다. 회의 내용은 회의록 파일에만 순서대로 기록해두고, 사용자가 "회의 끝났다"고 알리면 그때 전체 안건을 최종 확인한 뒤 업무리스트를 일괄 업데이트한다.

**Why:** 안건이 진행 중일 때는 논의가 뒤집히거나("이건 업무리스트는 아니고 참고내용") 추가로 정정될 수 있어, 매 안건마다 즉시 아이템을 만들면 잘못된 항목이 쌓이거나 재작업이 생긴다. 회의 종료 후 전체를 보고 판단하는 게 더 정확하다.

**How to apply:** 회의록 작성 요청이 들어오면(예: "OO회의 진행" 후 안건 나열) 각 발화를 회의록 파일에 안건 섹션으로만 추가한다. 사용자가 명시적으로 "회의 끝", "회의 종료", "정리 끝" 등으로 마무리를 알리기 전까지는 [[project-work-item-classification]]에 따른 신규/기존 아이템 생성·수정을 보류한다. 종료 선언 후에는 회의록 전체를 다시 훑어 각 안건별로 업무리스트 반영 여부(신규/기존 매칭/참고용 제외)를 판단해 한 번에 반영하고, 대분류/연관공종도 그때 일괄 보고한다.
