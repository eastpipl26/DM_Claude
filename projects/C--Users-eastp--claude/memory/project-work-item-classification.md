SK하이닉스 용인 업무 items는 3개 분류축으로 관리한다:
- **축1 공종분류**: `대분류`(건축영역, array) + `연관공종`(소분류, array)
- **축2 성격**: 기존 `카테고리`(VO·TER·LL·간섭·시공성·법규·비용). "협의"·"도면오류"는 카테고리에서 폐지(도면오류는 rework원인에만).
- **축3**: `액션유형`·`rework원인` 유지.

**대분류(건축영역)**: 코어 / 마감 / 개구부 / 벽체·구획 / 레이아웃 / 지붕·외피·방수 / 구조체 / 양중·반입동선 / 인허가 / BIM / 사업관리
**소분류(연관공종)**: 구조 / 설비 / 전기 / 소방 / UT / 토목 / (없으면 `건축`)

**공종 귀속 룰(2026-07-26 도요 확정)**:
- 오수·우수: 건물 외=토목, 사이포닉·건물 내=설비
- 폐수=UT (→ CCSS=UT)
- AMHS·AMR·VBP=건축
- PGS 볼라드=UT
- 소분류 없으면 "건축" (기존 "건축단독" 표현 폐지)

**How to apply:** 신규 업무 item을 등록할 때마다 **항상 대분류·소분류를 판정해서 도요님께 알려준다**(도요 요청, 2026-07-26). 프론트매터에 `대분류`·`연관공종` 필드를 포함시킨다. 애매하면 위 귀속 룰 먼저 적용, 룰에 없으면 물어본다.
